# Q-Economics

A comprehensive platform for learning economics with interactive features, quizzes, research resources, and career guidance.

## Features
- Structured courses in Micro, Macro, Econometrics, Development, Finance
- Interactive graphs, quizzes, flashcards
- Search economic terms
- Test series for UPSC, RBI, UGC NET
- Research datasets, case studies, labs
- Careers guidance and job board
- Multilingual (English/Hindi)
- Mobile-friendly, accessibility compliant

## Tech Stack
- Static HTML/CSS/JS with Tailwind CSS, GSAP, Chart.js
- No backend; all static for easy deployment

## Deployment on Render
1. Push code to GitHub repository.
2. Go to render.com, create new Static Site.
3. Connect GitHub repo.
4. Build command: leave empty
5. Publish directory: / (root)
6. Deploy.

The site will be live at your-subdomain.onrender.com. For URL routing, the _redirects file handles clean URLs.

## Local Development
Open index.html in browser. For testing, use live server extension.

## Assets
- notes/ folder for PDF summaries and formula sheets (placeholders; add real PDFs)
- cases/ for case studies PDFs
- audio/ for lecture clips
